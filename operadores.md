#  🧮 *OPERADORES (MATEMÁTICOS Y LÓGICOS)*
---
 ### 1. **¿Por qué y para qué se utilizan?**

Los **operadores** permiten realizar operaciones con variables y valores. En Java, se dividen en varios tipos, pero los más comunes son:
#### Operadores Matemáticos (Aritméticos)
- `+` Suma  
- `-` Resta  
- `*` Multiplicación  
- `/` División  
- `%` Módulo (resto de una división)

#### Operadores de Comparación (Relacionales)
- `==` Igual a  
- `!=` Diferente de  
- `>` Mayor que  
- `<` Menor que  
- `>=` Mayor o igual que  
- `<=` Menor o igual que

#### Operadores Lógicos
- `&&` Y lógico (AND)  
- `||` O lógico (OR)  
- `!` Negación (NOT)	

Estos operadores se usan para realizar cálculos o comparar valores en estructuras como `if`, `while`, etc.

---

### **2.** Ejemplo de operadores matematicos en Java
```java
public class OperadoresEjemplo {
    public static void main(String[] args) {
        int a = 10;
        int b = 5;

        // Operadores aritméticos
        System.out.println("Suma: " + (a + b));
        System.out.println("Resta: " + (a - b));
        System.out.println("Multiplicación: " + (a * b));
        System.out.println("División: " + (a / b));
        System.out.println("Módulo: " + (a % b));

        // Operadores de comparación
        System.out.println("¿a es igual a b? " + (a == b));
        System.out.println("¿a es mayor que b? " + (a > b));

        // Operadores lógicos
        boolean x = true;
        boolean y = false;

        System.out.println("x AND y: " + (x && y));
        System.out.println("x OR y: " + (x || y));
        System.out.println("NOT x: " + (!x));
    }
} 
```

#### 💡 Nota Explicación 


// Este código muestra el uso de operadores básicos en Java.
